# RotaAlerta

Projeto acadêmico da disciplina de Desenvolvimento Front-End para Web.

## Objetivo

Facilitar o cadastro e a consulta de riscos nas estradas do interior,
relacionando os problemas às comunidades e aos acessos prejudicados.

## Diferencial

Relacionar os riscos das estradas às comunidades e aos acessos
prejudicados, como escolas, unidades de saúde e caminhos de escoamento
da produção. Os registros incluem pontos de referência locais para
facilitar a identificação do trecho.

## Categorias

- Buracos e asfalto danificado.
- Animais soltos na pista.
- Obstáculos e passagens obstruídas.
- Alagamentos e deslizamentos.
- Falta de sinalização.

## Funcionalidades

- Navegação entre início, cadastro e consulta.
- Cadastro de categoria, nível de perigo, descrição e localização.
- Identificação da comunidade e do principal acesso afetado.
- Informação sobre a condição da passagem.
- Consulta e filtros combinados por categoria, comunidade e acesso.
- Exclusão de ocorrências com confirmação.
- Armazenamento dos registros no navegador.
- Exemplos fictícios identificados como dados demonstrativos.
- Layout adaptável a diferentes larguras de tela.

## Tecnologias

- HTML: estrutura, navegação e formulários.
- CSS: aparência, layout, responsividade e animações.
- JavaScript: eventos, validação, consulta, filtros e exclusão.
- localStorage e JSON: armazenamento local dos registros.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o index.html usando a extensão Live Server.
4. Utilize o menu para cadastrar e consultar ocorrências.

## Limitações

Este projeto é um protótipo local. Não há compartilhamento de registros
entre usuários, banco de dados online ou navegação GPS.

Os dados podem ser apagados ao limpar o armazenamento do navegador.
Os relatos não garantem que um caminho esteja seguro ou atualizado.
