# RotaAlerta

Projeto acadêmico da disciplina de Desenvolvimento Front-End para Web.

## Objetivo
Facilitar o registro e a consulta de riscos nas estradas do interior.

## Diferencial
Relacionar os riscos às comunidades e aos acessos afetados, como
escolas, unidades de saúde e caminhos de escoamento da produção.
Os registros também terão pontos de referência para identificar o local.

## Funcionalidades planejadas
- Cadastro e consulta de ocorrências.
- Filtros por categoria, comunidade e acesso afetado.
- Armazenamento dos registros no navegador com localStorage.

## Tecnologias
HTML, CSS e JavaScript.

## Limitação da primeira versão
Os registros serão armazenados apenas no navegador utilizado,
sem compartilhamento entre usuários.
